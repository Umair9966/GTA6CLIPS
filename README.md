# GTA 6 Clips: REPLAY RIOT

12 vertical YouTube Shorts (1080×1920, 2:22–2:41 each) edited from **real GTA 6 gameplay released under
the Creative Commons Attribution licence (CC BY)**, plus the channel branding and the tools that built them.

> Videos in this repo are compressed copies (~4.4 Mbps, under GitHub's 100 MB file limit) for review and
> sharing. Upload the full-quality originals to YouTube.

Each `videos/NN_clip/` folder contains:
- `final.mp4`: the Short (compressed copy)
- `thumbnail.jpg`: branded cover
- `metadata.txt`: title, description **with the required CC BY credits**, hashtags, hook, pinned comment, editing plan
- `source_and_license_notes.txt`: exact source videos, licences, and rights notes
- `qa_report.json`, `render_log.json`, `captions.ass`: technical QA (all PASS) and the edit decision list

## Tools
- `tools/shorts_studio/`: the render/QA/paperwork layer (built on top of
  [SupoClip](https://github.com/FujiwaraChoki/supoclip)): framing, zooms, freeze frames, replays, captions,
  watermark, SFX, loudness, rights gate and QA.
- `tools/cc_pipeline/`: `plans.json` (the edit plan for every video), `build_cc.py` (plan → manifest +
  music) and `make_video.py` (music synthesis and graphics helpers).

Rebuild a video (after downloading the CC sources into `_source_footage/cc/`):
```
python tools/cc_pipeline/build_cc.py 04
cd tools/shorts_studio && python -m studio render 04 && python -m studio qa 04
```
Paths in the scripts point at `D:/GTA6_SHORTS`; edit `config/project.json` and the constants at the top of
`build_cc.py` for another machine.
